# 原型计划字段 / Prototype planning sheet

仅填有关字段，复用项目已有文档。Fill relevant fields only; reuse project documentation.

| 字段 / Field | 应说明 / Capture |
| --- | --- |
| 决定 / Decision | 本次问题与结果会改变的选择 / Question and decision it informs |
| 背景 / Context | 新项目或既有版本、受众、输入、平台、范围与权限 / New or existing version, audience, inputs, platform, scope and authority |
| 证据 / Evidence | 已观察、用户陈述、源码事实、假设、未知分开 / Observations, reports, source facts, assumptions, unknowns separately |
| 规则 / Rules | 输入、行动条件、状态转移、反馈、结束观察及恢复 / Inputs, legality, transitions, feedback, observation ending and recovery |
| 因果链 / Causal chain | 规则到体验，最弱环节与竞争解释 / Rule to experience, weakest link and competing explanation |
| 载体 / Medium | 最小载体、必要保真度、不能证明什么 / Smallest medium, necessary fidelity and limits |
| 试验 / Comparison | 对照、变体、不变项、必要与排除任务 / Control, variant, held conditions, included and excluded tasks |
| 决策门 / Decision gate | 信号、反证、采集方式、适用阈值或待定 / Signals, counterevidence, collection, contextual thresholds or unknowns |
| 退出 / Exit | 继续/调整/停止/证据不足，回退与下一负责人 / Continue/adjust/stop/inconclusive, rollback and next owner |

## 教学示例 / Teaching example

开放式音乐玩具：问题是“玩家能否听出两种组合方式的区别”。试验可保持音色与输入不变，仅改变组合规则。必须保留足够音频保真度，不能用纯纸面比较证明听觉辨识。观察玩家能否描述差异，以及是否只是音量不同造成判断。无需添加敌人、分数或胜负。本例未实际运行，没有通过结论。

Open-ended music toy: ask whether players can distinguish two combination rules. Hold timbre and inputs fixed while changing the rule. Preserve enough audio fidelity; paper alone cannot establish auditory discrimination. Observe descriptions of the difference and whether loudness is the competing cause. Enemies, scores and winning are unnecessary. This example has not been executed and has no pass verdict.
