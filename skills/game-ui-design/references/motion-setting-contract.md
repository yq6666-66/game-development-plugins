# 减少动态效果：配置与玩家信息合同

[English](motion-setting-contract.en.md)。只用于当前任务涉及的动态 UI 或附加镜头效果；不自动增加第一/第三人称切换或改玩法。

## 来源与边界

Microsoft / Xbox Accessibility Guidelines，[XAG 117](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117)，页面更新 2026-11-13，读取 2026-11-18。已读目标、概述、范围问题、实施指导和示例说明文字；未观看链接视频或核对配图像素。无固定引擎版本、源码或运行证据。来源建议让玩家控制非必要动态内容；不能据此要求冻结整个游戏世界。这里只作原创方法综合，不复制素材或作医学安全保证。

## 本仓库提出的最小验证流程

1. 列当前屏幕的动态效果、触发事件、所有者和承载的信息。先区分装饰与规则/必要反馈。是否可关闭及替代反馈由项目合同决定。
2. 写明设置语义：关闭是停留当前帧、复位到静态基线还是隐藏？即时生效还是下次进入生效？保存作用域是什么？不把“强度为零”视作完成证据。
3. 在获准的副本中比较同一事件的默认与减少效果路径；保留玩家需要的状态、方向或结果信息，不通过暂停游戏、跳过事件制造通过。
4. 检查效果进行中切换、退出后重入、再次触发；若项目承诺持久化，再检查重启。核对实际画面和设置值，防止旧动画任务恢复已关闭效果。
5. 用已有正常输入确认相机控制、菜单焦点和游戏时序未被意外改变。改动规则或输入响应时，另列玩法验收，不能只叫视觉优化。

记录：设置/效果 → 生效时机 → 静态或替代反馈 → 重入/持久化 → 实际证据。没有设备或用户测试时标未验证。屏幕录像只能说明该样本的变化，不能证明所有玩家舒适、光敏安全或完整无障碍达标；相关专项另行评估。成本包括生命周期追踪及同一事件的双路径回归，不引入新依赖。
