# 资产到实时画面的阶段门

在导入、批量资产、材质排错、动画或性能任务中按需读取；不是要求每次都执行完整管线。沿用现有工具链，只检查本单元涉及的阶段。下列是方法蒸馏，不表示上游示例或用户工程已经通过运行验证。

## 1. 一件资产的运行合同

按覆盖风险先选少量代表资产，记录：
- 源路径、版本/完整哈希、许可与第三方依赖、批准状态；导出文件、导入设置及运行场景之间的对应关系。
- 用途、实际观察距离、单位/轴向/朝向、比例/枢轴、命名节点、材质槽、贴图通道/色彩空间、必要的扩展和解码器。
- 如涉及动画：rest pose、骨架映射、动作名、根运动所有者、循环方式、事件与预览/最终输出的区别。
- 可见几何与碰撞代理分开；LOD、贴图和性能预算没给定就写未知，不套通用面数或分辨率。

参考图逐张说明借配色、形状、材质还是层次，以及不借什么。原件只读，从已批准基线迭代，不无限把生成结果再喂给生成器。已批准母版库只收通过项；设计变更另立基线，不混用新旧参考。检查实际产物尺寸、alpha、图层偏移和受保护区，不能只相信请求参数或蒙版。HUD数字与本地化文本从真实数据渲染，不烘成生成图片。代码许可不自动覆盖模型、训练集、输出、字体和音频；可商用不明时保留阻塞，不凭根 LICENSE 下结论。

## 2. 导出、再导入、实际运行各过一关

| 阶段 | 必须取得的证据 | 不能据此声称 |
| --- | --- | --- |
| 源与导出 | 输入和输出存在、元数据、完整哈希、日志 | 导出0退出等于所有资产正确 |
| 再导入 | 逐项比尺度、方向、节点、骨架、UV、材质贴图与动作 | Blender中可见等于Unity/网页相同 |
| 目标运行 | 实际入口加载、当前有效质量/管线、真实尺度与玩家视角 | 模型加载无错等于光照、交互、碰撞通过 |
| 正常输入 | 约定路线及动态遮挡/控制回归 | 调试相机、瞬移、自动tour等于玩家流程 |

优化、合并或压缩前查节点名、层级和材质是否被小地图/交互/动画引用。不能为减 draw call 破坏语义结构。共享资产卸载前查所有者，避免释放仍在使用的材质/纹理。重复导入应不漂移，不重设正确的轴、比例、origin、材质槽；Unity GUID/meta、Prefab overrides和序列化引用需重新加载核验。

修改前确定唯一真源及生成/同步映射，避免编辑下次会被覆盖的导出结果。几何检查包括modifier评估后的网格和法线，不只原始对象。批次列出 N 件中检查 M 件、每件成功/失败及未覆盖项。缺目录写 BLOCKED；扫描没找到代码引用只说明检索未发现，不能直接删除“孤儿”资产。

## 3. 用隔离实验定位画面错误

1. 先查几何、相机、加载和裁剪，再查有效灯光、阴影覆盖、环境反射、曝光与色调映射。白屏/首帧缺图也可能是捕获方式问题，不先改游戏。
2. 用同一几何/灯光/机位比较材质；颜色贴图与标量/法线数据的色彩空间分别核实。粗糙度和光滑度极性、ORM通道不能盲搬；色调映射不要重复执行。
3. 临时无光照材质、线框或调试视角仅作隔离证据，恢复后再正常输入验证。UV存在不等于拉伸/接缝质量合格。
4. Shader效果检查关闭/零值、开启和结束端点，检查阴影/深度pass、坐标/UV及目标后端。编译成功不证明目标GPU无闪烁。
5. 动画看短动作完整播放、左右/根运动/脚滑/手指/循环接缝；每帧共用画布/尺度/锚点。透明素材用明暗背景核查真实alpha，不把棋盘格当透明。只看首帧或数字评分不算通过。

## 4. 性能测量资格

记录设备/GPU、引擎与构建类型、真实渲染后端、分辨率/DPR、质量档、场景路线、测量时长及电源/热状态。临时解除VSync/限帧用于诊断后须恢复，不将测试设置遗留为产品改动。

先分CPU、GPU、GC、IO/加载、物理与资源尺寸，选最大且相关瓶颈。报告可取得的帧时间分布（如平均、p95/p99、尖峰）而非只给平均FPS；冷启动/第一次效果和暖态持续运行分开。用同条件交错A/B，不能用降低画质后更快的结果掩盖视觉损失。暂无采样写未测，不写0成本；下载、安装、内存、补丁大小也不是同一指标。

音频另按真实事件、材质与空间验收，分开音乐/SFX/对白；实际试听及运行触发缺一不可，视频配音不能证明游戏音频正确。

目标设备缺失则保留未验证。离线逐帧60fps录制、headless CPU测试和编辑器数据分别标注，不能宣称真机实时达标。避免按“new必分配”“Vector3相减分配”之类泛化判断优化，以目标运行时Profiler证明。

外部作业超时或响应丢失时先核对同一任务ID及状态，不误重发造成重复收费。dry-run/估价也须核工具真实语义与参数层级；已有凭据不是付费、上传或运行授权。

## 5. 结论与依赖绑定

证据记目标版本、受影响源码/资产/配置、方法、设备和输入路径。相关依赖改变后旧PASS要重新评估；不可只更新主文档哈希继续沿用所有结论。风险被接受仍不是PASS。保留同机位前后图、正常路线日志、未覆盖项与回退点，在任务约定的交付与复核点停止。
