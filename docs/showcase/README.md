## 投稿信息模板

- 作品名、作者、介绍、项目类型与目标平台。
- 演示/仓库链接及访问条件；作品提交版本、日期与实际运行入口。
- 使用了哪些 Skills、对应版本，解决什么问题，哪些部分由其他工具完成。
- 修改前后证据、实际输入流程、结果、失败与未验证范围。
- 学到的方法、成本、反例与对插件的改进建议。
- 公开展示授权、源码/素材/截图/音频许可，需署名内容；不要上传凭据、私人路径或未经许可的资源。

只按实际证据描述，不能把作品存在归因于插件全部能力，也不将截图当作完整可玩证明。投稿不自动发布、合并或代管游戏。作品可保存在独立仓库，本仓库按授权保留介绍与链接。
