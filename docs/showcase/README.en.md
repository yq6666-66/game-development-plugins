**No works have been submitted or verified here yet.** This page reserves a way to showcase games made using the bundle. No game, source or asset upload is part of this increment.

## Submission template

- Title, author, description, project type and target platforms.
- Demo/repository links and access requirements; version, date and actual startup entry.
- Skills and versions used, problems solved and contributions from other tools.
- Before/after evidence, actual input steps, results, failures and untested scope.
- Lessons, costs, counterexamples and suggested plugin improvements.
- Public-display authorization and source/asset/image/audio licenses and attribution. Exclude credentials, private paths and unauthorized resources.

Describe only supported results. Do not attribute the whole game to the bundle or treat screenshots as complete playability evidence. Submission does not automatically publish, merge or host a game. Games may stay in separate repositories, with authorized descriptions and links here.
