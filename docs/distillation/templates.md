# 研究、候选与周报模板

[English](templates.en.md) · [教程](README.md)

复制需要的字段即可，不为填表编造信息。以下均为模板，不是已完成研究记录。

## 每日记录：`docs/research/daily/YYYY-MM-DD.md`

- 日期、目标仓库、实际默认分支、基线提交、工作分支。
- 已检查的历史记录与未合并分支；本次主题数量与减少原因。
- 每个主题：原始链接、作者、日期、版本/提交、读取范围。
- 问题与对象、核心机制、步骤和取舍、使用条件、输入输出。
- 最小验证方法、失败经验、成本与不适用条件。
- 来源状态：正文/字幕/源码已读、仅作者声称、未取得主体。
- 运行状态：实际环境与结果，或未运行；自己的推断另列。
- 对应 Skill/能力缺口、拟改文件、判断有效的标准。
- 重复来源的新增价值；实际修改、检查、提交链接、遗漏与阻塞。

## 候选改进：`docs/research/candidates/YYYY-MM-DD/主题.md`

- 判断与来源；哪些是来源结论，哪些是自己的推断。
- 触发场景、适用条件、输入输出、最小流程。
- 归入既有 Skill 的理由，或新增 Skill 的独立职责依据。
- 拟改文件与兼容风险；反例、最小验证、通过条件。
- 状态：线索 / 草案 / 待验证 / 可审阅 / 暂缓；依据与下一步。

## 周报：`docs/research/weekly/YYYY-Www.md`

- 上一自然周的起止时间（Asia/Shanghai）、实际覆盖日期与遗漏。
- 当前默认分支基线；纳入日分支与提交 SHA；已合并与去重情况。
- 价值发现、共同方法、差异与矛盾、实际整合文件。
- 采用优先级、成本、验证；未纳入内容及原因；下周问题。
- 每个自主判断：一句话判断、依据、推理、范围、不确定性、反例、最小验证、对插件的影响。
- 包检查、情境推演、宿主加载、游戏运行分别记录；周分支与提交链接。
