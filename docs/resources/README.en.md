# Tools, applications, engines and resources

[中文](README.md) · [Navigation](../navigation/README.en.md)

This is a recommendation format, **not a verified resource directory yet**. Any engine, framework, language, native API, custom or mixed toolchain may be assessed against project needs. Free pricing does not establish commercial or redistribution rights or unlimited service access.

For on-demand research, use [game-resource-selection](../../skills/game-resource-selection/SKILL.md). It guides current evidence checks rather than shipping fixed recommendations.

## Conditional recommendation template

- Name, official URL, maintainer, check date and reference version.
- Problem, audience, project stage and exclusions.
- Engine/platform/hardware/host conditions; dependencies and inputs/outputs.
- README/code/examples/issues inspected; execution environment or “not run.”
- Free limits, paid features, quotas/subscriptions and external services; label unknowns.
- License, commercial use, attribution, modification and redistribution terms; check each asset.
- Minimal trial, observable result and removal/rollback path.
- An alternative without adding the tool; benefit, maintenance cost and risk.
- Decision: suitable / conditional / unverified; related Skill.

A recommendation does not authorize installation, account creation, upload, payment or technology migration. Recheck changed versions and terms.
