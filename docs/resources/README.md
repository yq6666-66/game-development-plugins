# 工具、应用、引擎与资源

[English](README.en.md) · [分类导航](../navigation/README.md)

本页提供推荐记录格式，**尚不是已核验的推荐目录**。任何引擎、框架、语言、原生 API、自研方案或混合工具链都可按项目需求评估。免费只是成本条件，不代表可商用、可再分发或没有服务限额。

按需研究可以使用独立的 [game-resource-selection](../../skills/game-resource-selection/SKILL.md)。它指导核查当前证据，不内置静态推荐结论。

## 条件化推荐模板

- 名称、官方链接、维护者、检查日期、参考版本。
- 要解决的问题、适合对象、项目阶段与不适用条件。
- 引擎/平台/硬件/宿主兼容条件；必要依赖与输入输出。
- 已读 README/源码/示例/问题记录的范围；实际运行环境或“未运行”。
- 免费范围、收费功能、额度/订阅与外部服务；未知项明确写未知。
- 许可证、商业使用、署名、修改与再分发条件；素材逐项核对。
- 最小试用步骤、可观察结果、卸载/回退方式。
- 至少说明“不引入该工具”的替代路线；收益、维护成本和风险。
- 推荐结论：适用 / 条件适用 / 待核验；与相关 Skill 的关系。

推荐不是安装、账号注册、上传数据、付费或迁移技术栈的授权。版本与许可变化后重新核验。
