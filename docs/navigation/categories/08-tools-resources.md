# 工具与资源推荐

[English](08-tools-resources.en.md) · [返回八类导航](../README.md)

## 何时使用

需要选择引擎、框架、应用、工具链或素材，而不是默认照搬示例工具。

## 输入与交付

- 输入：任务、平台、预算、已有技能/工程、数据敏感度及许可需求。
- 交付：有日期与来源的条件化比较、最小试用与退出方案。

## 两条起步路径

- **从零开发：**从目标和约束筛选，允许原生 API、自研、混合方案或不引入工具。
- **接手项目：**优先核对现有工具是否能完成任务，再比较替换收益和迁移成本。

## 当前可用入口

[game-resource-selection](../../../skills/game-resource-selection/SKILL.md)。阅读真实入口及本次需要的目录内参考，不一次加载全部资料。

提供选择方法与推荐卡模板，不声称维护了完整、实时或全部免费的产品目录。

## 最小检查

核查官方版本、费用、依赖、输入输出、许可与维护；免费不等于可商用或可再分发。推荐不是安装、上传或付费授权。
