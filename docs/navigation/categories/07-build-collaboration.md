# 构建与协作

[English](07-build-collaboration.en.md) · [返回八类导航](../README.md)

## 何时使用

构建不可复现、交接不清或需要准备发布/回退；准备不等于授权发布。

## 输入与交付

- 输入：目标平台、版本/依赖、构建入口、产物约定、权限与分支策略。
- 交付：构建说明、产物身份、验证日志、交接清单与回退方式。

## 两条起步路径

- **从零开发：**先确定一个目标平台和可复现的本地构建路径；不默认注册服务或部署。
- **接手项目：**读现有构建/CI 和分支记录，检查实际使用的版本及缓存边界，不盲改配置。

## 当前可用入口

[项目约定](../../examples/project-contract.md)。阅读真实入口及本次需要的目录内参考，不一次加载全部资料。

本页是协作导航清单，不是可安装的构建 Skill；发布、部署、签名与付费仍按任务授权。

## 最小检查

在授权环境构建并核对日志/产物，再单独检查启动和相关操作；构建退出码不能证明游戏可玩。没有执行就标未运行。
