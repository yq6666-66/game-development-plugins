# Tools & resources

[中文](08-tools-resources.md) · [All categories](../README.en.md)

## When to use

An engine, framework, app, toolchain or asset must be selected rather than copied from an example.

## Inputs and output

- Inputs: Task, platform, budget, skills/project, data sensitivity and licensing needs.
- Output: Dated, source-backed conditional comparison, minimal trial and exit plan.

## Starting routes

- **New project:** Select from goals/constraints, allowing native APIs, custom or hybrid approaches and no new tool.
- **Existing project:** Check whether existing tools suffice before comparing replacement benefits and migration cost.

## Available entry

[game-resource-selection](../../../skills/game-resource-selection/SKILL.md). Read the actual entry and only its needed local references.

Provides selection methods and review-card templates, not a complete real-time or all-free product catalog.

## Smallest check

Check official versions, costs, dependencies, I/O, licenses and maintenance; free does not mean commercially reusable or redistributable. Recommendations do not authorize installation, uploads or payment.
