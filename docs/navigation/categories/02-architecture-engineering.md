# 架构与工程

[English](02-architecture-engineering.en.md) · [返回八类导航](../README.md)

## 何时使用

职责、状态所有权、依赖或工程入口不清楚；不是默认重构整个项目。

## 输入与交付

- 输入：启动入口、版本锁定、模块/状态清单、依赖与保护项。
- 交付：职责与依赖图、一个最小改动边界、运行方式及回退点。

## 两条起步路径

- **从零开发：**先选满足目标平台的最小结构，记录关键接口；复杂架构需有具体收益。
- **接手项目：**先读真实文件并运行现有入口；定位状态写入者与生命周期，不另造框架。

## 当前可用入口

[game-engineering](../../../skills/game-engineering/SKILL.md)。阅读真实入口及本次需要的目录内参考，不一次加载全部资料。

独立工程 Skill 已提供从方案到授权内最小切片的流程；不是预制引擎工程或跨引擎运行认证。

## 最小检查

追踪一条输入到状态到界面的数据路径，并检查退出/重开后的归属；静态依赖图不能证明运行正确。
