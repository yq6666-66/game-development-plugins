# 玩法与系统

[English](04-gameplay-systems.en.md) · [返回八类导航](../README.md)

## 何时使用

输入、规则、状态、重开、存档或反馈与预期不符。

## 输入与交付

- 输入：规则、状态所有者、输入路径、正常/异常结果与复现条件。
- 交付：可重复的操作步骤、状态前后对照、反例与回归结果。

## 两条起步路径

- **从零开发：**按已授权规则验证最小循环；未知规则先标假设或向决策者确认。
- **接手项目：**定位已有系统的问题，保护有效规则；不借修复之名新增玩法。

[game-playloop-validation](../../../skills/game-playloop-validation/SKILL.md)。阅读真实入口及本次需要的目录内参考，不一次加载全部资料。

## 最小检查

正常输入走完一个相关循环，再重复或中断；测试存档只在项目有该能力时进行，不因导航列出就新增。
