# 界面与体验

[English](05-ui-experience.en.md) · [返回八类导航](../README.md)

## 何时使用

玩家看不懂状态，HUD 不同步，菜单焦点、文字输入或多设备布局有问题。

## 输入与交付

- 输入：界面状态清单、输入设备、语言/尺寸、信息优先级与可访问性目标。
- 交付：状态/焦点转换表、关键屏幕证据及可操作路径。

## 两条起步路径

- **从零开发：**先列玩家必须知道的信息和必要操作，再设计一屏及其错误/退出状态。
- **接手项目：**检查 UI 读取的真实状态与输入归属，区分显示错误、状态错误与操作不可达。

## 当前可用入口

[game-playloop-validation](../../../skills/game-playloop-validation/SKILL.md)。阅读真实入口及本次需要的目录内参考，不一次加载全部资料。

现有入口提供界面验证，不是完整 UI 设计系统或全面无障碍认证。

## 最小检查

用实际支持的输入进入、操作和退出界面；检查返回、取消、重开、文字输入与关键声音的视觉信息。模拟尺寸不等于真机通过。
