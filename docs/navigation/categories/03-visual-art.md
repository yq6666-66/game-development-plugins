# 画面与美术

[English](03-visual-art.en.md) · [返回八类导航](../README.md)

## 何时使用

风格不一致、资产导入差异、材质/光照或画面可读性有问题。

## 输入与交付

- 输入：参考、真实资产、单位/轴向、渲染配置、目标视角与设备。
- 交付：视觉目标、小样本、受控前后对比及运行风险记录。

## 两条起步路径

- **从零开发：**先建立代表性小区域与材质/模型样板，再增加内容和效果。
- **接手项目：**保存原件，核对导入约定；先定位差异来自资产、材质、灯光还是运行配置。

## 最小检查

相同机位与观察条件对比，只改变实验变量；离线渲染不能替代实时截图，美术通过不能替代玩法通过。
