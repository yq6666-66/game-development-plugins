## 3. 自主综合判断：适用条件与反证

### 判断一：同一操作的“完成”按可兑现承诺拆开

交付资源与加载两份 Godot 文档加上 11-22 导航（请求成功可先于路径、路径可先于实际到达）支持这一推断，不是说三者 API 或失败机制相同。找一次获取成功但接入失败，以阶段与当前所有者记录第一个承诺破裂；旧结果可缓存而不得抢当前场景。反例：同步小屏一步原子完成，无需引入多段异步状态；已获准的视觉降级可让玩法继续，但报告不能称完整素材。低成本检查是离开 A 再选 B 并让 A 晚到，另让 B 获取成功但接入失败。此轮示意断言已跑，未运行场景。已影响工程、构建的入口与参考。

### 判断二：采样对齐、实际合成和玩家理解不能互为认证

XAG 102 的最不利背景、11-21 的同源轨迹反例和 11-22 的历史帧输入共同说明：先确认样本身份，再看最终合成，再按正常操作检查可读反馈。反例：静态高对比告示并不需要逐帧录制，也不能由两帧推断用户理解；跨硬件的 HDR 模式仍需设备验证。低成本试验是在同一动作/状态配对一个明暗背景，再故意隐藏关键元素；不应让仅配色、时间戳或选取有利帧的检查假绿。本轮跑示意覆盖断言，未测实际像素或理解。已影响 UI 参考；动态媒体证据暂不复制。
